# PCB Expo 0.5

Обновление приложения для подготовки LCD-засветки печатных плат на **Creality HALOT-MAGE S** и экспорта раскладки для CNC. Версия приложения: **0.5.0**. Тег: `v0.5.0`.

## Изменения после 0.4

- Обновлён интерфейс: панель команд, сворачиваемые секции, компактные числовые поля, закреплённый экспорт, предупреждения и сводка проекта. Обновлены окна DXF/CNC, калибровки, справки, подтверждения экспорта и «О программе». Начальные размеры окон учитывают рабочую область экрана.
- Текущая маска экспортируется в PNG в полном разрешении LCD, в ориентации предпросмотра и с физическим масштабом отдельно по X/Y для фотошаблона и лазера.
- Для меди и паяльной маски засвечивается свободное поле между платами. Вокруг каждой платы сохраняется тёмный контур 0,5 мм; центровочные отверстия остаются тёмными.
- Общая толщина служебных линий управляет точками центровки, окружностями отверстий, рамкой текстолита и геометрической калибровкой. Внешний размер квадрата остаётся 50 × 50 мм, длина линии 100 мм. Значения старых проектов и профилей сохраняются.
- В центровке доступны окружности внутри отверстий и рамка снаружи текстолита; предпросмотр показывает фактический растр.
- Добавлены пояснения компенсации и справка по оценке результатов калибровки: горизонтальные и вертикальные линии и просветы, выбор времени и компенсации.

## Файлы выпуска

| Файл | Назначение |
| --- | --- |
| `PcbExpo-0.5.0-win-x64.zip` | Автономное приложение для Windows x64, руководство и лицензии. Отдельная установка .NET не требуется. |
| `PcbExpo-0.5.0-source.zip` | Исходники PCB Expo, тесты и скрипты сборки из тега выпуска. |
| `SHA256SUMS.txt` | SHA-256 обоих архивов. |
| `release-manifest.json` | Версия, тег, коммит и дерево исходников, платформа и сведения о файлах. |

Распакуйте Windows ZIP полностью и запустите `PcbExpo.App.exe`. Затем выберите собственный шаблон `.cxdlpv4` и папку или ZIP Gerber. **Шаблон принтера и рабочие файлы плат в выпуск не включены.**

## Проверки и ограничения

Сборка проходит автоматические Release-тесты с фиксированными зависимостями, включая headless-проверки интерфейса. Упакованный EXE проверяется на версию 0.5.0, загрузку OpenCV и работу PNG-кодека.

Физическая работа на HALOT-MAGE S и станке пока не подтверждена. Масштаб, направление рисунка, время, PWM и компенсация требуют проверки на своём оборудовании и материале. Нативные диалоги и масштабирование Windows на физическом мониторе отдельно не проверялись.

Раскладка содержит копии одной платы без поворота. Категории сверловки выбираются по целым Excellon-файлам; смешанную сверловку следует разделить в CAD. DXF содержит геометрию 1:1 в миллиметрах, подготовка траекторий выполняется в CAM.
