# PCB Expo 0.4 — предварительная версия

Первый публичный выпуск приложения для подготовки LCD-засветки печатных плат на **Creality HALOT-MAGE S** и экспорта раскладки для CNC. Версия приложения: **0.4.0-preview**. Тег: `v0.4.0-preview`.

## Файлы выпуска

| Файл | Назначение |
| --- | --- |
| `PcbExpo-0.4.0-preview-win-x64.zip` | Автономное приложение для Windows x64, руководство и лицензии. Отдельная установка .NET не требуется. |
| `PcbExpo-0.4.0-preview-source.zip` | Исходники PCB Expo, тесты и скрипты сборки из тега выпуска. |
| `SHA256SUMS.txt` | SHA-256 обоих архивов. |
| `release-manifest.json` | Версия, тег, коммит исходников, платформа и сведения о файлах. |

Распакуйте Windows ZIP полностью и запустите `PcbExpo.App.exe`. Затем выберите собственный шаблон `.cxdlpv4` и папку или ZIP Gerber. **Шаблон принтера и рабочие файлы плат в выпуск не включены.**

## Что доступно

- Медь и паяльная маска Top/Bottom; одна плата или сетка на заготовке.
- Фотополимерный паяльный трафарет по PasteMaskLayer с центровочными отверстиями.
- Калибровка масштаба, матрица подбора времени/компенсации и отдельные экспозиционные пробы.
- Один бинарный слой CXDLPV4 в разрешении LCD с повторным чтением и сравнением пикселей.
- DXF для CNC с полной раскладкой и выбором контуров, вырезов и категорий сверловки.
- Светлый интерфейс, логотип и иконка, предпросмотр в разрешении LCD внутри выделенной области.
- Сохранение проектов и профилей.

## Проверки и ограничения

При подготовке выпуска пройдены **110 автоматических тестов**, включая доступные локальные Gerber и шаблон LCD 13320 × 5120. Проверены полярность трафарета, состав CNC, повторное чтение однослойных файлов и защита исходного шаблона. В проверке интерфейса подтверждены светлая тема, встроенная символика, размер растра, ограничение увеличенного изображения и сохранение результата последнего выбранного режима. Упакованный exe проходит проверку версии, загрузки OpenCV и PNG-кодека.

Выпуск имеет статус **pre-release**. Физическая работа на HALOT-MAGE S и станке пока не подтверждена. Проверьте масштаб, направление рисунка, время, PWM и компенсацию на своём оборудовании и материале.

Раскладка содержит копии одной платы без поворота. Категории сверловки выбираются по целым Excellon-файлам; смешанную сверловку следует разделить в CAD. DXF содержит геометрию 1:1 в миллиметрах, подготовка траекторий выполняется в CAM.
