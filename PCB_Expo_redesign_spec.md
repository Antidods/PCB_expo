# PCB Expo 0.4.0-preview: спецификация редизайна и переноса в Avalonia

Дата: 07.10.2026. Основа: исходники `D:/PROJECT/PCB_expo` (MainWindow.cs, UiText.cs, PreviewControl.cs, DxfExportWindow.cs, DxfPreviewControl.cs, ExposureCalibrationWindow.cs, CalibrationHelpWindow.cs, AboutWindow.cs, Program.cs), скриншот 0.4.0-preview.
Прототип: холст «PCB Expo — редизайн» (Design-артефакт). Все значения в прототипе демонстрационные: пути с пометкой `[демо]`, рисунок платы условный, раскладка «Заполнить заготовку» рассчитана упрощённо. Параметры принтера (13320 × 5120 px, 223 × 126 мм, шаг X 0,016742 / Y 0,024609 мм) и габарит платы 35,560001 × 25,4 мм взяты со скриншота.

## 4. Локальные изменения (основной вариант)

Без изменений: PcbExpo.Core, enum, формат `*.pcbexpo.json`, профили, алгоритмы, обработчики, тексты ошибок.

**Program.cs**
1. `new FluentTheme { Palettes = { [ThemeVariant.Light] = new ColorPaletteResources { Accent = Color.Parse("#6418D8"), RegionColor = Color.Parse("#EEF0F4") } } }`. API палитры проверить для Avalonia 12.1.2.
2. Стили по классам, скоупом через `Style.Resources` на ключи Fluent (`ButtonBackground`, `ButtonBackgroundPointerOver`, `ButtonBackgroundPressed`, `ButtonForeground*`, `ButtonBorderBrush*`):
   - `Button.primary`: Accent, белый текст, MinHeight 38, FontSize 14, SemiBold;
   - `Button.toolbar`: прозрачный фон и рамка, hover `#F0F1F5`;
   - `Button.chip`, `Button.chip.on`; `Button.link`;
   - `TextBox`: MinHeight 28, Padding 8,4, CornerRadius 4; `TextBox.num`: TextAlignment Right;
   - `TextBlock.caption` 12 `TextMuted`; `TextBlock.h` 13 SemiBold `Heading`;
   - `Border.note`, `Border.note.warn`, `Border.alert`, `Border.alert.warn`, `Border.alert.err`;
   - `Expander`: заголовок 13 SemiBold, прозрачный фон, нижний разделитель.
3. `Window.Background = #EEF0F4`, `FontSize = 13`.

**MainWindow.cs**
1. Корень: Grid `RowDefinitions="44,*,26"`, `ColumnDefinitions="320,*,280"`; панель команд и строка состояния на `ColumnSpan=3`.
2. Панель команд (пп. 1–3 таблицы).
3. Левая панель: блок режима + 4 Expander (пп. 5–22).
4. Центр: заголовок предпросмотра, Border вокруг `_preview`, подсказка (пп. 23–26).
5. Правая колонка: закреплённый экспорт + ScrollViewer (пп. 27–32).
6. `Section()`, `Button()`, `Number()` → `Section()` с Expander, `Button(label, action, cls)`, `CreateNumberBox`, `Row`, `Pair`.
7. `UpdateSummary()` перестраивает три Grid сводки и список предупреждений из `UiText.SummaryParts`.
8. `ConfirmExport()` (п. 33).
9. Значения окна: оставить `Width=1560, Height=940, MinWidth=1100`; `MinHeight` снизить с 700 до 600 (см. раздел 6).

**UiText.cs**: добавить `SummaryParts(...)`; `Summary()` собирать из него, чтобы текст подтверждения экспорта не изменился.

**PreviewControl.cs**: фон `#D9DDE4` вместо `Brushes.WhiteSmoke`. Растр, наложения и жесты не трогаются.

**DxfExportWindow.cs, ExposureCalibrationWindow.cs, CalibrationHelpWindow.cs, AboutWindow.cs**: только компоновка и классы стилей (пп. 34–38).

Выводы: `MinHeight` снизить до 600 (проверено на 1000 × 600: панели прокручиваются, экспорт виден). `MinWidth` 1100 ограничен шириной панели команд; для 1366 × 768 при 125 % нужен либо О-7 + `MinWidth` ≈ 1080 со сжатием панели команд (не проверено), либо принять ограничение.
