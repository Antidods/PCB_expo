# PCB Expo

Локальное Windows-приложение для подготовки экспозиционных масок печатных плат на Creality HALOT-MAGE S.

Исходный рабочий файл `150x100.cxdlpv4` и пример EasyEDA Gerber остаются локально и не включаются в Git. Шаблон нужен для сохранения параметров формата и принтера при экспорте.

Проект находится в разработке. Порядок сборки, система координат и проверенные ограничения будут добавлены вместе с реализацией.
